# Mt. SAC Computer Science Club Links

A centralized, mobile-friendly link hub for the Mt. SAC Computer Science Club. It brings the club's Discord, interest form, Instagram, and contact email together in one place.

## Club links

- [Discord](https://discord.gg/QwaV2EY2CB)
- [Club interest form](https://forms.gle/odS1nMzKg7xvBEd57)
- [Instagram](https://www.instagram.com/cs.mtsac/)
- [Email](mailto:mtsac.csclub@gmail.com)

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```
